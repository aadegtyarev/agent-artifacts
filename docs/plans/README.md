# Plans

Agreed ideas that are not built yet, in the order they are planned. Each
becomes wireframes, then a mockup on the real code, then code.

1. **Full screen: double tap on the floating ≡ exits.** A hint in the icon;
   on entering full screen a tip "Hold — comments · Double-tap — exit full
   screen" with OK (shows again, up to 3 times) and Hide (never again).
2. **Desktop interface.** Designed against [the design system](../design/README.md).
3. **Group invitations for workshops and demos.** A link (and a QR of it) for
   N people until a date; each person picks a name and gets a key at once.
   Defaults 20 people and 7 days (up to 200 and 30). If N × the per-person
   quota does not fit the free space, each gets the free space ÷ N, said at
   creation. The organiser can see who joined and close it; removing everyone
   who joined is a separate, confirmed step.
4. **Codes to open a file on another device.** An 8-character code, valid
   5 minutes, entered on the main page; the field shows only while a code is
   live. Wrong tries are limited.
5. **Devices and settings on the server.** Linking a phone to the same person
   by a code; then name, theme, text size, pins and dot colour follow the
   person instead of living in one browser.
6. **Storage by kind.** HTML, PDF, images, text and Markdown kept while there
   is room; when space runs short the agent lists files by upload and last
   view and the person decides. Archives removed 60 minutes after the first
   download.
7. **Sign-in and storage providers (Google).** See [providers.md](providers.md).
